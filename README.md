# 가상 초파리 신경회로 실험

VS Code에서 **초파리 실험 실행 (디버그)** 구성을 실행하거나 `serve_sim.py`를 실행하면 Chrome에서 실험이 열립니다.

## 필요한 자료

- `지도.png`: 이동 환경으로 사용하는 지도 이미지
- `file_csv/connections_princeton.csv`: 시냅스 연결 원본 자료
- `file_csv/neurons.csv`: 입력 뉴런의 좌·우 측면 메타데이터
- `file_csv/neuron_role_assignments.csv`: 모델에서 사용할 steering/forward 역할 지정

연결 원본은 용량이 커서 Git에서 제외됩니다. 실행할 때 로컬 `file_csv` 폴더에 있어야 합니다. Python 서버가 실행 시 연결 데이터와 지도를 읽고 역할 뉴런별 입력 합계 및 통로 마스크를 준비합니다.

## 실험 방법

1. 짙은 회색 통로 위에서 시작점과 목표점을 차례로 선택합니다.
   마우스 대신 지도를 포커스한 뒤 방향키와 Enter/스페이스로 지정할 수도 있습니다.
2. **학습**을 누르면 Python에서 여러 번의 가상 시행을 수행합니다. 학습 상태에는 목표 방향, 주변 이동 가능 방향, 지도상의 대략적인 위치 구역이 포함됩니다.
3. **실행**을 누르면 Python 모델이 매 스텝마다 학습값과 연결 수 가중 회로 편향으로 이동을 결정하고, 브라우저는 결과를 그립니다. 최단 경로 탐색으로 이동 경로를 대신 계산하지 않습니다.

HTML/JavaScript는 지도 표시, 사용자 입력, Python API 요청만 담당합니다. 연결 입력은 서버 시작 시 역할 뉴런별 좌·우 입력 시냅스 합으로 집계해 매 스텝마다 원본 연결을 다시 순회하지 않습니다. 학습값은 현재 서버 프로세스의 메모리에만 보관되며 서버를 다시 시작하면 초기화됩니다.

## 해석 범위

이것은 connectome-informed 소프트웨어 프로토타입이지 실제 초파리 실험이나 생물학적으로 검증된 행동 모델이 아닙니다. 뉴런의 `steering`/`forward` 역할, 좌·우 입력 해석, 보상 함수는 사용자가 지정한 가정이며 행동 근거는 검증되지 않았습니다. 지도 위에서의 이동 결과를 실제 초파리 행동의 증거로 해석하지 마세요.
